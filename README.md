# Connect4Game

 # 🎮 Connect Four – Human vs AI (with Minimax + Alpha-Beta)

This project is a graphical version of the classic *Connect Four* game built using *Python* and *Pygame*. It includes a competitive AI opponent powered by the *Minimax algorithm with Alpha-Beta pruning* and a custom evaluation function.

---

## 🧠 Features

- ✅ Turn-based *Human vs AI* gameplay
- 🧠 Smart AI with *Minimax + Alpha-Beta Pruning*
🎯 Improved evaluation function for strategic play
🕳️ AI blocks winning moves and defends aggressively
y
- 🖥️ Polished *Pygame GUI* with animations
🔁 "Play Again" button for restarting
